# Библиотека незаконченных сказок

Играбельный браузерный прототип комнатного roguelite / twin-stick shooter. Ребёнок попадает в библиотеку, где каждая книга братьев Гримм становится отдельным этажом с искажённой историей, своими противниками и боссом.

По структуре боя, находок и исследования проект вдохновлён *The Binding of Isaac*, но использует собственный сеттинг, предметы и правила.

**[Играть в браузерную версию](https://k8rvin.github.io/bureau-of-unreturned-things/)**

## Запуск на Windows

Нужен **Node.js 18 или новее**. Устанавливать production-зависимости не требуется.

1. Запустите `START.bat` двойным кликом.
2. Откроется `http://127.0.0.1:8080/`.
3. Не закрывайте окно сервера во время игры. Для остановки нажмите `Ctrl+C`.

Альтернатива из терминала в корне проекта:

```bash
npm start
```

Затем откройте http://127.0.0.1:8080/ вручную.

## Что реализовано

- Один главный герой — ребёнок с собственными направленными анимациями.
- Шесть книжных этажей с разными окружениями, противниками и боссами.
- Комнатные бои, исследование карты, сокровищницы, магазины, мастерские, испытания и секреты.
- **39 вещей и 10 синергий**, включая мультивыстрел, тяжёлые залпы, луч, яд, кровотечение, рикошеты и возвращающиеся снаряды.
- Размер снаряда показывает его фактический урон.
- Охотник стреляет настоящими стрелами с временем полёта, а не мгновенным лучом.
- Трёхсекундная задержка перед выбором награды после боя.
- Пауза с описанием полученных вещей и текущими характеристиками сборки.
- Открытие новых вещей за прохождение книг и усложнённые испытания, без постоянной покупки урона или здоровья.
- Отдельный режим тренировки боссов без наград и прогресса основного забега.
- Возможность остаться на этаже после победы над боссом.
- Сохранение и продолжение текущего забега.

Это работающий прототип, а не завершённый по балансу релиз. Следующая калибровка сложности выполняется по результатам обычных боёв.

## Управление

| Клавиша или действие | Назначение |
| --- | --- |
| `WASD` | Движение |
| Мышь | Независимое прицеливание |
| ЛКМ | Стрельба светом страницы |
| `R` | Установить петарду |
| `E` | Взаимодействие |
| `F` | Золотая закладка после открытия секрета |
| `Tab` | Удерживать полную карту |
| `M` | Скрыть или показать миникарту |
| `Esc` | Пауза, вещи и характеристики |
| `F8` | Включить или выключить локальную статистику боя |

В настройках можно выключить звук, уменьшить эффекты и включить дополнительные траектории вражеских атак. Траектории по умолчанию выключены.

Диагностика записывает игровое время, фактический урон, полученные удары, сборку и ресурсы. Хранятся не более восьми локальных сессий. Данные не отправляются в сеть и не смешиваются с сохранением забега. По умолчанию сбор выключен; для разработки его также активирует параметр `?debug=1`.

## Документация и ассеты

- [DESIGN.md](DESIGN.md) — концепция, принципы, правила и результаты проверок.
- [GEMINI.md](GEMINI.md) — создание, визуальная приёмка и нарезка изображений.
- [assets/ATTRIBUTION.md](assets/ATTRIBUTION.md) — источники, лицензии и ограничения ассетов.
- [assets/library/manifest.json](assets/library/manifest.json) — игровые спрайты, комнаты и их обработка.

Основные изображения заранее созданы через Gemini и нарезаны в игровые атласы. Сторонние ресурсы сохранены с их условиями. Для эффектов используется локальная версия `pixelfx`.

## Технологии и структура

- Vanilla JavaScript, Canvas 2D, Web Audio.
- Статический Node.js-сервер без production-фреймворка.
- `src/` — игровые системы, интерфейс, предметы, этажи и противники.
- `assets/library/` — готовые PNG-спрайты, фоны, иконки и манифесты.
- `vendor/pixelfx/` — эффекты и их лицензия.
- `tools/` — локальный сервер и инструменты сборки ассетов.

Стандартная проверка синтаксиса:

```bash
npm run check
```

http://127.0.0.1:8080/bureau.html
